⌨️ 微软拼音 · 小鹤音形配置指南

在微软拼音中加载小鹤双拼方案与音形自定义短语词库（ChsPinyinEUDPv1.lex），附手心 / 搜狗输入法版本建议与配置文件下载。

1加载小鹤双拼方案

以管理员身份打开 CMD 命令提示符，执行下面的命令，将小鹤双拼键位方案写入微软拼音注册表：

reg add HKCU\Software\Microsoft\InputMethod\Settings\CHS /v UserDefinedDoublePinyinScheme0 /t REG_SZ /d "小鹤双拼*2*^*iuvdjhcwfg^xmlnpbksqszxkrltvyovt" /f
✅
执行成功会提示「操作成功完成」。随后到 设置 → 时间和语言 → 语言 → 中文(简体，中国) → 选项 → 微软拼音 → 常规 → 双拼方案 中选择「小鹤双拼」。

2删除旧短语 & 加载音形词库文件

同样在 CMD 环境下执行：先删除旧的自定义短语词库，再从云端下载小鹤音形词库覆盖到微软拼音目录。

del "%APPDATA%\Microsoft\InputMethod\Chs\ChsPinyinEUDPv1.lex" & powershell -Command "Invoke-WebRequest -Uri 'https://share5.s3.bitiful.net/t/ChsPinyinEUDPv1.lex' -OutFile '%APPDATA%\Microsoft\InputMethod\Chs\ChsPinyinEUDPv1.lex'"
⚠️
该命令会先删除现有的自定义短语词库！如果你已有自己的短语，请先备份： 可用 MSPhraseTool 的 export 命令导出 CSV，或用 网页版转换工具 导入现有 .lex 留存。
📌
命令中的 %APPDATA% 由 CMD 负责展开，请在 CMD 中运行，不要在 PowerShell 窗口中运行。
执行后若未生效，请重启微软输入法或重启电脑；提示「文件被占用」时，关闭所有使用输入法的程序再试。
